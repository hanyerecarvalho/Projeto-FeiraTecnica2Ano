# 🌎 Projeto Feira Técnica — Exploração do Planeta Terra

Aplicação web interativa desenvolvida para a Feira Técnica do curso Técnico em Informática, com o objetivo de apresentar informações sobre o planeta Terra de forma visual, moderna e interativa.

O projeto permite explorar uma representação 3D da Terra e acessar diferentes informações relacionadas ao planeta, como cidades, localização geográfica, clima e astronomia.

## 🚀 Funcionalidades

- 🌎 Visualização 3D do planeta Terra
- 🔎 Pesquisa de cidades
- 🌦️ Informações climáticas
- 📍 Informações geográficas
- 🌌 Informações astronômicas
- 🖥️ Interface moderna e interativa
- 📱 Layout adaptável para diferentes dispositivos

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript - FrontEnd
- PHP Framework Slim - BackEnd
- Tecnologias de visualização 3D
- APIs para obtenção de informações
- Git e GitHub

## 🎓 Objetivo

O projeto foi desenvolvido como parte da Feira Técnica do curso Técnico em Informática, buscando unir programação, tecnologia e conhecimentos sobre o planeta Terra em uma aplicação interativa e educativa.
